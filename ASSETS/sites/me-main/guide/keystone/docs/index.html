ks-input

The label is always rendered and associated — a placeholder is not a label. The error state carries a border, an icon, and text, is wired with aria-invalid and aria-describedby, and announces through a live region.

Generated guidance

The build emits a skill file alongside the CSS. It is not written by hand, so it cannot fall out of date with the tokens — which is the whole failure mode of documentation as a separate artifact.
