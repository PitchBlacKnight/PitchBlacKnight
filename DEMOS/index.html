02 · Systems craft — Pathfinder 2.0
Pathfinder 2.0866 tokensZero dependenciesNo build step

A design system rebuilt as a live framework

The AVANT partner portal design system, extracted 1:1 from its published spec site into a token-pure component library: buttons, badges, data tables, modals, cards, stat tiles, forms, tabs, toasts, and a responsive app shell. Components consume var(--pf*) exclusively, so retheming is a token-file swap. Fonts are vendored, it renders identically with the network off.

What this demonstratesTokens as the API, spec-site fidelity, and a system built so that both humans and agents can assemble from it.

03 · Agentic AI — systems that agents operate
The stageLive demo surface~1s from prompt to pixels

Talk to the agent, components appear on screen

The centerpiece of the live demo: a browser canvas that hot-swaps whatever the agent writes onto the screen within a second, no refresh, no build step. A skill file teaches the agent the tokens, the component anatomy, and the spec-site rules (max 7 table columns, mono for data, always a cancel path), so what appears is on-system by construction, not by luck.

What this demonstratesThat a design system rigorous enough to be written down as rules becomes a system an agent can build with, correctly, in real time.

This deployed copy shows the last assembled build. The live hot-swap runs locally during a demo, see the interview kit for the 6 to 8 minute run-of-show.

KeystoneAgent-operated pipeline

The token pipeline, enforced

Three-tier DTCG tokens with one-way flow enforced by the build, accessible web components, and machine-readable component metadata generated from the same source. Metadata records carry a source checksum, edit a component and the build reports it stale and exits non-zero.

Paired with three agent skills: a producer that encodes the rules, a composer that builds screens from the metadata, and a steward that audits drift.

open the docs
Figma pluginTokens Out

Figma variables → W3C DTCG

A real Figma plugin built with the Plugin API. It reads every local variable collection and emits standards-compliant DTCG JSON, the platform-agnostic format a Style Dictionary pipeline consumes. A source-of-truth migration, in miniature.
